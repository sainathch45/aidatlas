# Reference photo attribution

PRD Section 11 ("Staged stubble-pile reference photos") calls for real
reference photos with a known grade, used in the demo instead of an
uncontrolled live camera capture. This directory holds those.

## paddy_stubble_coorg_dry_example.jpg

- **Source:** Wikimedia Commons, [File:Paddy Stubble Balamuri Coorg Feb24 A7C 09417.jpg](https://commons.wikimedia.org/wiki/File:Paddy_Stubble_Balamuri_Coorg_Feb24_A7C_09417.jpg)
- **Author:** Timothy A. Gonsalves (Wikimedia user Tagooty)
- **License:** CC BY-SA 4.0 -- requires attribution, derivatives must carry a compatible license
- **Resized** from the 3,168 x 4,752 original to fit under 1024px on the long edge for API payload size; otherwise unedited
- **Live-verified grade (2026-10-15):** Gemini's multimodal read returned "dry" on one run and "wet" on another for this same image -- a real, honest finding, not hidden: this specific photo sits at a genuinely ambiguous point (likely morning dew visible on otherwise dry standing stalks), which is exactly why the PRD treats this signal as a soft matching input the solver can take or leave, never a price input.

Before using this image in a public pitch deck or demo video, contact the
author per the file page's request and credit him as asked.
